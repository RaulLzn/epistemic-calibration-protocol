# Security Policy

This project is a text-level mitigation for AI behavior. It is not a security boundary.

Do not use it as the only safeguard for:

- medical decisions,
- legal decisions,
- financial decisions,
- safety-critical systems,
- cybersecurity authorization,
- identity or access control,
- high-stakes moderation,
- or autonomous deployment decisions.

For high-impact use, combine it with trusted retrieval, independent verification,
human review, logging, monitoring, and domain-specific evals.

To report a safety issue, open a GitHub issue with a minimal reproduction and mark
the expected failure mode.
